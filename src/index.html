编辑排谷数据

💡 操作提示：

1. 点击单元格可直接编辑；
2. 支持从Excel复制内容直接粘贴到表格；
3. 品类总价会根据单价和总数量自动计算；
4. 剩余数量会根据排的人CN数量自动计算；
5. 排的人CN支持编辑（多个名字用顿号分隔）；
6. 所有修改会自动同步到云端；
7. 可删除单行数据或清空所有数据
🔍 表格搜索：
品类 谷子图片URL 单价 总数量 剩余数量 品类总价 捆序 排的人CN 操作

批量导入排谷认领数据

📌 推荐导入方式：
  1. 先导出Excel模板 → 填写数据 → 复制Excel内容粘贴到下方文本框
  2. 支持两种分隔符：制表符（Excel默认） 或 逗号/竖线（|）
  3. 列顺序：品类,单价,总数量,品类总价,捆序,排的人CN,图片URL（剩余数量会自动计算）
导入预览（点击行可查看详情）

1. 肾表自动根据排谷数据生成；

3. 点击"打印小票"可生成样式一致的PDF小票；
4. 运费支持手动设置，会自动均摊到每个认领人；
5. 可按金额/点数/CN排序
